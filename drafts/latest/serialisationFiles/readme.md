# mobilityDCAT-AP Serialisation files

The following serialisation files allow for IT implementations of mobilityDCAT-AP.

- The [RDF/XML](address_agent_shape.ttl) is a SHACL node shape that defines the structure and constraints for the locn:Address class.
- The [Turtle](agent_shape.ttl) is a SHACL node shape that defines the structure and constraints for the foaf:Agent class. 
- The [JSON-LD ](assessment_shape.ttl) is a SHACL node shape that defines the structure and constraints for the mobilitydcatap:Assessment class.
