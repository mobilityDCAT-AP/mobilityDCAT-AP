Usage note

In mobilityDCAT-AP, this class is only used as the range of property geodcatap:referenceSystem for class Dataset, denoting a spatial reference system. This class is not used to inform about a (mobility) data standard applied to the delivered data. For this, mobilityDCAT-AP introduces a separate class mobilitydcatap:MobilityDataStandard, used as the range of property mobilitydcatap:mobilityDataStandard of class Distribution.
