Definition A legal document, e.g., a concrete license, giving official permission to do something with a resource.
URI

dct:LicenseDocument

References

Usage note

It may be used to concretise the generic intellectual property rights (IPR) information, as provided for a distribution via class dct:RightsStatement.

However, if a concrete (standard) licence is defined for the distribution, it should be provided via this class, so a data user can assess the license conditions in machine- and human-readable formats, before using the data.

Properties

This specification does not impose any additional requirements to properties for this entity.
